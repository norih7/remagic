# ドメイン用語集

RE:MAGIC（テイルズ オブ エターニア攻略サイト）で使われるゲーム用語と、サイト内のデータ用語をまとめるディレクトリです。

- [用語集](./glossary.md): ゲームシステム、攻略コンテンツ、データモデルの用語

## 読み方

- **ゲーム内**: テイルズ オブ エターニアの攻略記事で使う意味
- **サイト内**: このリポジトリの画面、JSON、TypeScriptで使う意味
- **根拠**: 主に `src/app`、`src/constants`、`src/data`、`src/lib`、`src/db` の実装・データを示します

リマスター版で仕様が変わる可能性がある項目や、ソース内で定義が不足している項目は「要確認」として扱います。
